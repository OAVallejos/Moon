This paper derives the projection of the O_h vacuum lattice anisotropy onto the interferometric (u,v) plane, predicting a hexagonal modulation in polarization signatures. We demonstrate that sampling this effect requires long baselines, necessitating the implementation of an Earth-Moon interferometric antenna.
